# 还原情况说明

本文说明 3 套测试素材（共 30 页）中各类元素被还原成了什么、哪些能编辑、哪些只能退化为图片。

## 一、素材特征（决定了整体路线）

| 素材 | 页数 | 页面尺寸 | 每页内容 | 文字层 | 矢量层 |
|---|---|---|---|---|---|
| 测试1.pdf | 10 | 852×1212 pt | 1 张整页 JPEG（852×1212，约 72dpi） | 无 | 无 |
| 测试2.pdf | 10 | 852×1212 pt | 同上 | 无 | 无 |
| 测试3.pdf | 10 | 852×1212 pt | 同上 | 无 | 无 |

三套都是「PPT 导出成图片再拼成 PDF」，所以 **PDF 图层里没有任何可提取的结构**，只能：
像素 → OCR 文字 → 版面分析 → 分层重建。凡是这一步做不出来的复杂视觉，就按题目允许的方式保留为独立图片对象。

## 二、逐类元素还原方式

| 元素类型 | 还原方式 | 输出对象 | 可编辑程度 |
|---|---|---|---|
| 标题 / 副标题 / 正文 | OCR 行 → 按行距与对齐方式合并成段落 | 文本框（每段一个） | 改字、字号、颜色、加粗、对齐、拖动 |
| 小字注释 / 页码 / 页脚 | 同上 | 文本框 | 同上 |
| 照片 / 产品图 / 渲染图 | 色差+边缘掩码 → 连通域 → 去字后裁剪 | 图片 | 移动、缩放、替换、裁剪 |
| Logo / 图标 | 同图片，按小面积阈值保留 | 图片 | 同上 |
| 装饰性矢量图形（斜切色块、圆环、半透明带、连接线） | 与背景色差明显 → 作为图形块 | 图片（或并入背景层） | 作为图片移动缩放 |
| 表格（测试1 第 8 页「产品参数·规格表」） | 横线定行 + 文字列投影定列 + 单元格单独 OCR | PowerPoint 原生表格（11 行 × 5 列） | 单元格改字、增删行列、改填充 |
| 图表（测试3 第 8 页折线图 + 条形图） | 整块识别为图形区域 | 图片 | 仅能移动/缩放（数据不可反推） |
| 页面背景 | 纯色 → 原生矩形；渐变/底纹 → 去字后的背景图 | 矩形 或 背景图片 | 改填充色 / 换背景图 |
| 整版大图页（封面、深色封面） | 整页作为「去字背景图」+ 文本对象 | 背景图 + 文本框 | 文字可编辑，底图可替换 |

## 四、明确无法完全还原的内容

1. **图表的数据语义**：折线图/柱状图的数据点、坐标轴刻度是像素不是数据模型，只能整块作为图片，不能双击改数据。
2. **装饰性矢量图形**：斜切色块、半透明渐变带、发光圆环、虚线连接线等，没有对应的 PPT 形状语义，保留为图片对象；位置与视觉一致，但不能再改形状参数。
3. **阴影 / 发光 / 半透明叠加**：属于图像效果，随图层保留在图片里。
4. **表格细节**：单元格底色、文字颜色、行列尺寸已还原；但**合并单元格、单元格内多段落对齐、斜线表头**未做还原，跨列被 OCR 读成一行的内容靠「单元格单独重识别」纠正，仍有误差。
5. **字体**：原设计字体（思源/方正系列）统一映射为「微软雅黑」，字宽已按墨迹校正，但字形与字重仍会有差异。
6. **OCR 误差**（已记录的真实样例）：
   - 「柯幻熊猫」被识别为「柯幻解猫」（个别页）；
   - 「按需定制」漏字成「按定制」；
   - 英文单词间空格偶有遗漏（已用墨迹间隙补回大部分，如 `BUILD A BETTER TOMORROW`）。
7. **极小元素**：面积小于页面 0.04% 且不是细线的小装饰会并入背景层，不再单独成对象。
8. **页眉页脚合并**：部分页脚「公司英文名 | 产品名 | 页码」会被 OCR 连成一行，文本内容正确但被合并进同一个文本框。

## 五、结论

- 30 页全部输出为 PPTX，PowerPoint / WPS 均可正常打开。
- 文字 100% 作为**可编辑文本对象**存在（共 7219 个字符），没有任何一页是「整页截图塞进去」。
- 图片全部是**独立图片对象**（共 207 个），可单独移动缩放。
- 唯一的原生表格（测试1 第 8 页）已还原为 11×5 的 PowerPoint 表格。
- 逐页结构相似度 0.90~0.99，平均 0.946。
